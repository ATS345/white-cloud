### 1.3 设计规格

#### Hero 轮播区域
- **高度**: 600px (桌面) / 400px (移动)
- **图片比例**: 16:9
- **文字区域**: 左侧 40%，渐变遮罩从左到右
- **轮播切换**: 淡入淡出，4秒自动播放
- **指示器**: 底部居中，圆点样式

#### 游戏卡片
- **卡片尺寸**: 280px × 200px (封面 280×158)
- **卡片间距**: 24px
- **悬停效果**:
  - Y轴上移 4px
  - 阴影增强
  - 图片放大 1.05x
  - 边框变为主色
- **显示数量**: 桌面6个 / 平板4个 / 手机2个

#### 统计数据条
- **背景**: 主色渐变 (primary-500 → secondary-500)
- **内边距**: 40px 垂直
- **统计项**: 4列居中布局
- **数字样式**: 28px，JetBrains Mono 字体

- **宽度**: 280px (桌面) / 全宽 (移动，折叠面板)

- **搜索框**: 最大宽度 400px
- **排序选择**: 宽度 140px
- **视图切换**: 按钮组，网格/列表图标

#### 游戏卡片 (网格视图)
- **宽度**: 自动填充
- **封面比例**: 16:9
- **悬停效果**: 上移 4px + 阴影增强 + 边框变主色 + 图片放大

## 6. 响应式断点

| 断点 | 宽度 | 布局变化 |
|-----|------|---------|
| 超大屏 | >1400px | 最大容器 1400px |
| 大屏 | 1024-1400px | 最大容器 1200px |
| 平板 | 768-1024px | 侧栏折叠为抽屉 |
| 手机 | <768px | 单列布局，底部导航 |
