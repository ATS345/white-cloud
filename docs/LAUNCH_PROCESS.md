| 增量备份 | 每小时 | 7天 | 本地+云存储 |
| 配置备份 | 每次变更 | 永久 | 版本控制 |

### 4.2 备份执行脚本

```bash
#!/bin/bash
# 数据库备份脚本
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backup/database"
DB_FILE="dev.db"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 执行备份
cp $DB_FILE $BACKUP_DIR/dev_$DATE.db

# 压缩备份
gzip $BACKUP_DIR/dev_$DATE.db

# 清理30天前的备份
find $BACKUP_DIR -name "*.gz" -mtime +30 -delete

echo "Backup completed: dev_$DATE.db.gz"
```

### 5.3 Docker部署配置

```yaml
# docker-compose.yml
version: '3.8'
services:
  backend:
    build: ./backend
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
    volumes:
      - ./data:/app/data
    restart: always

  frontend:
    build: .
    ports:
      - "80:80"
    depends_on:
      - backend
    restart: always

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    restart: always
```

## 八、第七阶段：回滚预案

### 8.1 回滚触发条件

| 条件 | 描述 | 回滚决策人 |
|-----|------|-----------|
| 服务不可用 | 核心功能无法使用 | 技术负责人 |
| 数据异常 | 数据丢失或错误 | 技术负责人 |
| 性能严重下降 | 响应时间 > 5秒 | 运维负责人 |
| 安全漏洞 | 发现严重安全漏洞 | 安全负责人 |

### 8.2 回滚步骤

```bash
#!/bin/bash
# 回滚脚本

# 1. 停止当前服务
pm2 stop all

# 2. 切换到上一版本
git checkout HEAD~1

# 3. 恢复数据库备份
gunzip -c /backup/database/dev_latest.db.gz > dev.db

# 4. 重新安装依赖
npm ci

# 5. 构建应用
npm run build

# 6. 启动服务
pm2 start all

# 7. 验证服务状态
curl http://localhost:3000/health

echo "Rollback completed!"
```
