## 一、版本概述

云幕游戏商店平台是一个全栈游戏分发平台，提供游戏浏览、购买、下载、社区等完整功能。

### 核心功能

- ✅ 用户认证与授权
- ✅ 游戏浏览与搜索
- ✅ 购物车与订单管理
- ✅ 支付集成（支付宝/微信）
- ✅ 游戏下载管理
- ✅ 评论与社区功能
- ✅ 管理后台
- ✅ 监控与告警系统

## 二、更新日志

### 新增功能

| 功能 | 模块 | 说明 |
|-----|------|------|
| 用户系统 | auth, users | 注册、登录、个人中心 |
| 游戏商店 | games | 游戏列表、详情、搜索 |
| 购物车 | cart | 添加、修改、删除商品 |
| 订单系统 | orders | 创建、支付、取消订单 |
| 支付集成 | payments | 支付宝、微信支付 |
| 下载中心 | downloads | 游戏下载管理 |
| 评论系统 | reviews, comments | 游戏评价、用户评论 |
| 管理后台 | admin | 用户管理、游戏管理 |
| 监控系统 | metrics, alert | Prometheus指标、告警 |

### 优化改进

| 优化项 | 说明 |
|-------|------|
| Redis优雅降级 | 无Redis时服务正常运行 |
| 代码质量 | ESLint错误清零 |
| 安全加固 | JWT强制配置、权限校验 |
| 性能优化 | API响应时间<10ms |

### Bug修复

| 问题 | 修复方案 |
|-----|---------|
| JWT字段不匹配 | 统一使用id字段 |
| 购物车数量格式 | 返回{count: number}格式 |
| 订单空游戏列表 | 添加验证抛出BadRequestException |
| Admin权限缺失 | 添加@Roles('admin')装饰器 |
| Redis错误日志 | 添加null检查静默跳过 |

## 四、部署指南

### 本地运行

```powershell
# 后端
Set-Location backend; npm run start:prod

# 前端
npx serve dist -p 5173
```

### Docker部署

```powershell
# 配置镜像加速器后
docker-compose -f docker-compose.simple.yml up -d
docker-compose -f docker-compose.monitoring.yml up -d
```

### 环境变量

参考 `.env.production.example` 配置生产环境变量。
