## 快速开始

### 新用户入门

1. **注册账号**: 访问平台首页，点击"注册"按钮创建账号
2. **浏览游戏**: 在游戏列表页面浏览或搜索感兴趣的游戏
3. **购买游戏**: 将游戏加入购物车并完成支付
4. **下载游戏**: 在游戏库中下载已购买的游戏
5. **开始游戏**: 安装并启动游戏，开始您的游戏之旅

### 平台功能

| 功能模块 | 描述 |
|---------|------|
| **游戏商店** | 浏览、搜索和购买游戏 |
| **游戏库** | 管理已购买的游戏 |
| **购物车** | 管理待购买的游戏 |
| **订单管理** | 查看和管理订单 |
| **个人中心** | 管理个人资料和设置 |
