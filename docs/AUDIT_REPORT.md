### 6.1 已检测项

|--------|------|---------|

| 敏感信息暴露 | ⚠️ 需注意 | 中 |
| JWT密钥管理 | ⚠️ 需注意 | 中 |
| 权限校验 | ⚠️ 部分缺失 | 中 |

### 6.2 发现的安全问题

#### 问题1: JWT密钥硬编码风险 (中风险)

**位置**: `backend/src/modules/users/users.module.ts:11`
```typescript
secret: process.env.JWT_SECRET || 'default-secret',
```
**问题**: 使用了默认密钥作为fallback
**建议**: 移除默认密钥，强制要求配置JWT_SECRET

#### 问题2: admin-games模块缺少角色权限检查 (中风险)

**位置**: `backend/src/modules/admin-games/admin-games.controller.ts:21`
```typescript
@UseGuards(JwtAuthGuard)  // 只验证登录，未验证角色
```
**问题**: 任何登录用户都可以访问游戏管理接口
**建议**: 添加@Roles('admin')装饰器

#### 问题3: 敏感信息日志 (低风险)

**问题**: 生产环境可能记录敏感信息
**建议**: 配置日志脱敏
